# 📦 전개도 탐험대 3D

5학년 2학기 수학 5단원 「직육면체」 AI 융합수업용 3D 전개도 웹앱입니다.

- **① 접어 보기** — 정육면체 전개도 11가지 접기, 만나는 선분·꼭짓점 찾기
- **② 직접 만들기** — 6칸 색칠 → 정육면체 판정, 겹치는 면 표시
- **③ 직육면체 전개도** — 가로·세로·높이 변경, 마주 보는 면(합동) 확인
- **④ 성질·겨냥도** — 면·모서리·꼭짓점 세기, 평행·수직인 면, 겨냥도(실선/점선)
- **⑤ 퀴즈** — 10문제, 정답 후 3D로 확인

파일 하나(`index.html`)로 동작하며 Three.js(r128)를 사용합니다. 태블릿·휴대폰·PC 브라우저에서 바로 실행됩니다.
